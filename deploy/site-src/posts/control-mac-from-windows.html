Whether you’re helping someone with their MacBook or reaching your own iMac from a Windows laptop, you can control a Mac from a PC without any special network setup. This guide uses EnDesk, a free remote desktop app for Windows and Mac, and takes about five minutes the first time.

What you need

  • A Mac running macOS 12 (Monterey) or later, Apple Silicon or Intel.
  • A Windows 10 or 11 PC.
  • An internet connection on both. They don’t have to be on the same network.
  • Someone at the Mac for the first setup, to install the app and grant two permissions.

Step 1: Install EnDesk on the Mac

  1. Download the Mac version and open the .dmg file.
  2. Drag EnDesk into the Applications folder and open it.
  3. If macOS says it can’t verify the app, open System Settings → Privacy & Security, scroll down and click Open Anyway. You only do this once.

Step 2: Allow Screen Recording and Accessibility

macOS protects your screen and your keyboard and mouse from other apps. To let a remote computer see the Mac and control it, EnDesk needs two permissions:

  • Screen Recording lets EnDesk capture the screen so the Windows PC can see it. Without it, the remote side sees a blank or frozen picture.
  • Accessibility lets EnDesk move the pointer and type. Without it, you can see the Mac but clicks and keys do nothing.

EnDesk shows both on its main screen with an Open Settings button next to each. Turn EnDesk on in each list, then quit and reopen EnDesk so macOS applies the change.

These permissions belong to the Mac being controlled. A Mac that only controls other computers doesn’t need them.

Step 3: Install EnDesk on the Windows PC

  1. Download the Windows installer and run it.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway.
  3. Can’t install software on that PC? Use the portable version, which runs without installing.

Step 4: Connect

  1. On the Mac, EnDesk shows Your ID (nine digits) and a Password.
  2. On the PC, open EnDesk, choose Connect, type the ID and password, and press Connect.
  3. On the Mac, click Accept. The Mac’s screen appears on the PC, and your mouse and keyboard now control it.

To end the session, click Disconnect on the PC or Stop sharing on the Mac.

Using Mac shortcuts from a Windows keyboard

A Windows keyboard has no ⌘ key. By default the Windows key acts as ⌘ on the Mac. If you’d rather press Ctrl+C and Ctrl+V the way you do on Windows, turn on ⌘ ↔ Ctrl in the toolbar while connected, and Ctrl is sent as ⌘.

Reach the Mac when nobody is there

For your own Mac, you can skip the Accept step. In EnDesk’s Settings, set a permanent password, then turn on Unattended access. Keep the Mac awake: in System Settings → Energy (or Battery → Options on a laptop), prevent automatic sleep when the display is off. Read more in our guide to unattended remote access.

Troubleshooting

The screen is black or doesn’t update

Screen Recording isn’t allowed yet, or EnDesk wasn’t reopened after allowing it. Check System Settings → Privacy & Security → Screen Recording, then quit and reopen EnDesk.

I can see the Mac, but clicks do nothing

Turn on EnDesk under Accessibility and reopen the app. Also check that Control is on in the toolbar.

“No device online with that ID”

EnDesk must be open on the Mac, and its sidebar should show the server as Online. Double-check the nine digits.

The connection fails after Accept

Some strict networks block direct connections. EnDesk then relays the session automatically; if it still fails, try another network, such as a phone hotspot, to find out which side is blocking it.

Other ways to control a Mac from Windows

macOS has built-in Screen Sharing, which a Windows PC can reach with a VNC viewer. It works well on the same local network, but reaching it over the internet usually means router or VPN setup. Browser-based tools such as Chrome Remote Desktop also work and need a Google account. For a comparison, see free remote desktop apps for Windows and Mac.
