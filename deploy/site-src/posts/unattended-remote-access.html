Normal remote help is attended: someone sits at the computer, reads you a password and clicks Accept. Unattended access is for your own computers, like the office PC you want to reach from home or the home Mac you need while travelling. You connect whenever you like, and nobody has to be there.

How it works in EnDesk

EnDesk gives each session a fresh random password. Unattended access adds two settings on the computer you want to reach:

  • A permanent password that always works, alongside the session password.
  • The Unattended access switch, which accepts a connection automatically when the password is correct.

Set it up

  1. Install EnDesk on the computer you want to reach and open it.
  2. Go to Settings, enter a permanent password and click Save. Use a long, unique password, such as four random words.
  3. On This device, turn on Unattended access.
  4. On a Mac, make sure Screen Recording and Accessibility are allowed (details).
  5. Write down the 9-digit ID. You’ll connect with that ID and your permanent password.

Keep the computer reachable

A computer that is asleep, signed out or closed can’t be reached. Check these once:

Windows

  • Settings → System → Power: set sleep to Never when plugged in.
  • Keep the PC signed in. EnDesk runs in your session, so it can’t be reached at the Windows sign-in screen.
  • Leave EnDesk open. Closing its window quits it.

Mac

  • System Settings → Energy on a desktop Mac, or Battery → Options on a laptop: turn on “Prevent automatic sleeping when the display is off”.
  • Keep a MacBook on power with the lid open, or use it with an external display.
  • Keep EnDesk open. Add it under System Settings → General → Login Items so it starts after a restart.

Safety checklist

  • Use a strong permanent password that you don’t use anywhere else. EnDesk slows down repeated wrong guesses, but a strong password is your main protection.
  • Never share it. For one-off help, read out the session password instead, which changes every time.
  • Turn unattended access off when you no longer need it, and clear the permanent password.
  • Lock the screen when you leave if others can see the computer while you work on it remotely.
  • Read our guide to remote desktop safety to recognise tech-support scams.

Common questions

Can I wake a sleeping computer with EnDesk?

No. The computer has to be awake with EnDesk running, so set it not to sleep while plugged in.

Does unattended access work after a restart?

Only once you sign in again and EnDesk starts. Add EnDesk to your startup or login items so it opens automatically.

Is the session password still needed?

No. With a permanent password set, either password works. The session password is handy for letting someone in once.
