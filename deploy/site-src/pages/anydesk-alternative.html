A free AnyDesk alternative for Windows and Mac

EnDesk connects the same familiar way, with an ID and a password, and does that one job simply. It’s free for personal and work use, and there’s no account to create.

Download for Windows Download for Mac

AnyDesk is an established remote desktop tool with a lot of features. People look for an alternative for different reasons: they want something lighter, they only need to reach a few Windows and Mac computers, or they want a tool they can use at work without buying a licence. If that sounds like you, EnDesk is worth a try.

What feels the same

  • ID and password. Each computer shows a 9-digit ID and a password. Type them on the other computer and connect.
  • Approve each session. By default the person at the computer clicks Accept before anything is shared.
  • Unattended access. Set a permanent password to reach your own computers when nobody is there.
  • Works over the internet. No router setup or VPN. EnDesk connects directly when it can and relays the connection when a network blocks it.

What EnDesk doesn’t do yet

To be clear about it, EnDesk is simpler on purpose, and some things you may use in AnyDesk aren’t there today:

  • File transfer and clipboard sync
  • Phone and tablet apps, and Linux
  • Choosing between multiple monitors (EnDesk shares the main screen)
  • Remote audio, chat and session recording
  • Address books and team management

If you rely on these, keep the tool you have. If you mainly need to see and control another Windows or Mac computer, EnDesk does that well.

Switch in three steps

  1. Download EnDesk on both computers. Each needs EnDesk; it can’t connect to AnyDesk.
  2. On the computer you want to control, note the ID and password. On a Mac, allow Screen Recording and Accessibility once (how).
  3. On your computer, choose Connect, enter the ID and password, and wait for Accept.

Questions

Is EnDesk really free for commercial use?

Yes. EnDesk is free for personal and work use, with no licence and no time limits.

Can EnDesk connect to a computer running AnyDesk?

No. The two apps use different connection methods, so both computers need EnDesk installed.

Is EnDesk secure?

Sessions are encrypted end to end between the two computers, each session gets a new password, and you approve every connection unless you turn on unattended access yourself.

Does EnDesk work between Windows and Mac?

Yes, in both directions: control a Mac from a Windows PC, or a Windows PC from a Mac.
