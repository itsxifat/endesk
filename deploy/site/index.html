Control one computer from another — Windows ↔ Mac in either direction. Share the 9-digit ID and password shown in EnDesk, and connect.

First launch on Windows

  1. Run EnDesk-Setup.exe.
  2. If “Windows protected your PC” appears, click More info → Run anyway.
  3. Finish the installer and open EnDesk from the Start menu.

First launch on Mac

  1. Open the .dmg and drag EnDesk into Applications.
  2. Open EnDesk. If macOS says it can’t verify the app, open System Settings → Privacy & Security and click Open Anyway.
  3. To let this Mac be controlled, allow EnDesk under Screen Recording and Accessibility in the same settings page, then reopen EnDesk.

Connect

  1. On the computer you want to control, open EnDesk and read its ID and password.
  2. On your computer, open EnDesk → Connect, enter that ID and password.
  3. The other side clicks Accept (or set a permanent password in Settings for unattended access).
