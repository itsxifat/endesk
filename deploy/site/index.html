    Simple, and it stays out of the way.

    Windows and Mac

    Control a Mac from a PC or a PC from a Mac. ⌘ can map to Ctrl so shortcuts feel natural.

    Direct connection

    Screen and input go straight between the two computers for smooth video and quick response.

    Encrypted

    Every session is encrypted end to end. Our server introduces the computers and never sees the screen.

    You approve every session

    A new password each time, and nothing is shared until you click Accept.

    Unattended access

    Set a permanent password to reach your own computers when nobody is there.

    Works across networks

    Gets through home routers and office firewalls, with a relay when no direct path exists.

    Connected in three steps.

    01

    Read the ID

    Open EnDesk on the computer you want to control. Note its ID and password.

    02

    Connect

    On your computer, open EnDesk, choose Connect, and enter that ID and password.

    03

    Accept

    The other side clicks Accept. You now see its screen and control it.

    First launch

    Your computer asks once before opening an app downloaded from the web. That’s expected.

    Windows

    1. Open EnDesk-Setup.exe from Downloads.
    2. If you see Windows protected your PC, choose More info, then Run anyway.
    3. Finish the installer and open EnDesk from the Start menu.

    Can’t install apps on this PC? Use the portable version.

    macOS

    1. Open the .dmg and drag EnDesk to Applications.
    2. Open EnDesk. If macOS can’t verify it, go to System Settings → Privacy & Security and choose Open Anyway.
    3. To allow this Mac to be controlled, turn on EnDesk under Screen Recording and Accessibility, then reopen it.

    Only controlling other computers from this Mac? Skip step 3.

    Questions

    Does my screen go through your server?

    No. The server only helps the two computers find each other. The screen, keyboard and mouse travel directly between them, encrypted. When a network blocks a direct path, an encrypted relay passes the data along without being able to read it.

    Can someone connect without my permission?

    They need your ID and your current password, and by default you must click Accept. A permanent password only exists if you set one in Settings. Repeated wrong guesses are slowed down automatically.

    Why does my computer warn me the first time?

    Windows and macOS show a one-time prompt for apps downloaded outside their stores. Follow the First launch steps above; you only do it once.

    Is there a phone app?

    Not yet. EnDesk runs on Windows and Mac computers.
